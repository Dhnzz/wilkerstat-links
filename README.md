# Wilkerstat Links — BPS Kabupaten Gorontalo

Linktree pelatihan Wilkerstat BPS Kabupaten Gorontalo — single-page statis (HTML/CSS/JS vanilla), deploy Netlify + domain custom.

> Wayfinding map: lihat [map.md](./map.md) & GitHub Issues berlabel `wayfinder:*`.

## Cara update link

Edit `index.html` (atau `links.json` jika ada) — ganti `href="#"` dengan URL aktual, lalu push / drag-and-drop ke Netlify.

## Struktur

- `index.html` — halaman utama
- `assets/` — logo, foto kantor, background Gorontalo
- `map.md` — wayfinder map (tracker lokal, mirror dari GitHub Issue `wayfinder:map`)

## Deploy

Lihat Issue **Deploy Netlify + domain custom** untuk SOP lengkap.
